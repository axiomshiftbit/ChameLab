# Авторы и происхождение ChameLab

Этот форк не присваивает авторство исходных проектов. Авторские права на вклад
принадлежат его авторам; история Git и уведомления в отдельных файлах сохраняются.
Имена и лицензии зависимостей приведены в приложении: «Настройки → Авторы и лицензии».

Полный список участников каждого исходного проекта доступен по его истории Git
и странице Contributors. Для этого репозитория можно использовать `git shortlog -sn --all`;
для отдельного файла — `git log --follow --format=%an -- путь/к/файлу`.
Не следует заменять уведомления исходных авторов одним именем владельца форка.

Список лицензий Flutter-приложения не копируется механически: `chinese_font_library`,
`FlipperNestedRecovery` и `minlzma` не входят в .NET-приложение. Здесь применяются
управляемый hardnested и собственный набор библиотек, перечисленный в сборке.
